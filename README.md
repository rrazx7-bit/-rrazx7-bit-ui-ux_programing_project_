# 모아봄

여러 수업의 과제와 마감일을 한곳에서 정리하는 웹 서비스입니다. 마감이 가까운 일부터 확인하고, 끝낸 과제를 표시하며 남은 일정을 살펴볼 수 있도록 만들고 있습니다.

## 만들고 있는 기능

- 과목별로 과제와 마감일 모아 보기
- 마감이 가까운 순서로 오늘 할 일 정하기
- 완료한 과제와 남은 과제 구분하기

현재는 서비스 소개 페이지와 이메일 입력 화면을 구현했습니다. 과제 등록·저장과 알림 신청 기능은 아직 개발 전입니다.

## 페이지 구성

서비스 소개, 주요 기능, 이용 방법, 시작 알림 순서로 구성했습니다. 어떤 서비스인지 살펴본 다음 알림 신청 화면으로 넘어갈 수 있도록 했습니다. 상단 메뉴에서 원하는 항목으로 바로 이동할 수도 있습니다.

기능 목록의 `.feature-list`에 `display: flex`와 `gap: 20px`을 적용했습니다. 세 기능을 카드로 나란히 배치하고 사이 간격을 일정하게 맞춰, 각 기능을 한눈에 비교할 수 있도록 했습니다.

## 실행 방법

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 됩니다. 이미지가 함께 표시되도록 폴더 구조를 유지해 주세요.

HTML, CSS와 SVG로 작성했으며, 별도 설치나 빌드 과정은 없습니다. 화면 스타일은 `style.css`에서 수정할 수 있습니다.
