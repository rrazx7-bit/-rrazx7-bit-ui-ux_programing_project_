# 모아봄

여러 수업의 과제와 마감일을 정리하는 웹 서비스입니다. 해야 할 일을 적고 언제까지 진행할지 정해, 지금 시작할 과제의 계획을 확인할 수 있습니다.

[웹페이지 열기](https://rrazx7-bit.github.io/-rrazx7-bit-ui-ux_programing_project_/) · [프로젝트 저장소](https://github.com/rrazx7-bit/-rrazx7-bit-ui-ux_programing_project_)

## 사용자와 목표

- 주요 사용자: 여러 수업의 과제와 마감일을 정리하려는 대학생
- 서비스 목적: 흩어진 할 일을 구체적인 이름과 마감으로 정리하고 다음 행동을 정하기
- 핵심 행동: 과제 이름과 마감 방식을 입력하고 확인한 뒤 계획 확정하기
- 완료 조건: 입력한 과제 이름·과목·마감이 완료 화면에 표시되고, 사용자가 다음 행동과 새 계획을 시작하는 방법을 확인하기

현재는 과제 하나의 계획을 정리하는 화면을 구현했습니다. 내용은 현재 페이지에서만 유지되며 새로고침하면 지워집니다. 여러 과제의 목록 저장과 실제 알림 발송은 아직 지원하지 않습니다.

## 사용자 흐름

미리 체험에서 진입 → 과제 입력 → 마감 선택 → 내용 확인 → 완료

1. **진입:** 기존 과제 미리보기의 ‘과제 계획 세우기’를 누릅니다. 미리 적은 이름이 있으면 첫 입력창에 가져옵니다.
2. **입력:** 과제 이름을 적고, 필요하면 과목도 입력합니다. 이름은 필수이고 과목은 선택입니다.
3. **선택:** ‘마감일 지정’ 또는 ‘마감일 없이 시작’을 고릅니다. 마감일을 지정할 때만 날짜 입력이 나타납니다.
4. **확인:** 이름·과목·마감을 검토합니다. 이전 단계로 돌아가 수정하거나 확인 창에서 계획을 확정합니다.
5. **완료:** 정리한 계획과 다음 행동을 확인합니다. ‘새 계획 세우기’를 누르면 입력 단계부터 다시 시작합니다.

확인 창은 내용 확인 단계에 포함됩니다. 화면에는 입력·선택·확인의 진행 상태를 표시하고, 완료 후에는 ‘계획 완료’로 바꿉니다.

## 인터랙션 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 과제 계획 세우기 | `click` | 처음 진입 | 미리보기의 이름을 가져오고 입력창으로 초점을 옮깁니다. | 과제 입력 |
| 계획 이어서 보기 | `click` | 이미 시작한 계획이 있음 | 입력값을 덮어쓰지 않고 진행 중이던 화면으로 이동합니다. | 현재 단계 유지 |
| 마감 선택하기 | `submit` | 이름이 비었거나 공백뿐임 | 이름을 입력하라는 안내와 오류 표시를 띄우고 입력창에 초점을 둡니다. | 과제 입력 유지 |
| 이름 수정 | `input` | 오류 안내가 표시된 상태 | 해당 오류 표시를 지웁니다. 다음 버튼을 누르면 다시 검사합니다. | 과제 입력 유지 |
| 마감 선택하기 | `submit` | 이름이 있음 | 양끝 공백을 정리하고 마감 방식 선택으로 이동합니다. | 마감 선택 |
| 마감 방식 변경 | `change` | 마감일 지정 선택 | 날짜 입력을 표시하고 필수 입력으로 바꿉니다. | 마감 선택 유지 |
| 마감 방식 변경 | `change` | 마감일 없이 시작 선택 | 날짜 입력을 숨기고 날짜 값과 관련 오류를 지웁니다. | 마감 선택 유지 |
| 계획 내용 확인하기 | `submit` | 방식 미선택 또는 필요한 날짜 누락 | 빠진 항목의 수정 방법을 표시하고 해당 항목에 초점을 둡니다. | 마감 선택 유지 |
| 계획 내용 확인하기 | `submit` | 필요한 값이 모두 있음 | 입력한 이름·과목·선택한 마감을 요약에 반영합니다. | 내용 확인 |
| 이전 버튼 | `click` | 입력이나 선택을 수정하려 함 | 값을 유지한 채 바로 이전 단계로 돌아갑니다. 수정 후 진행하면 요약도 갱신됩니다. | 이전 단계 |
| 이 계획으로 시작하기 | `click` | 내용 확인 중 | 다시 확인과 계획 확정을 선택할 수 있는 확인 창을 엽니다. | 내용 확인 유지 |
| 다시 확인 또는 Escape | `click` / 키보드 취소 | 확인 창이 열림 | 창을 닫고 입력·선택·요약을 유지합니다. 초점은 원래 버튼으로 돌아갑니다. | 내용 확인 유지 |
| 계획 확정 | `click` | 확인 창이 열림 | 완료 안내, 정리한 계획, 다음 행동을 보여 줍니다. | 완료 |
| 새 계획 세우기 | `click` | 계획 완료 | 이름·과목·선택·날짜·오류·요약·진행 상태를 모두 초기화합니다. | 빈 과제 입력 |

이전 이동과 확인 취소는 수정할 내용을 남기고, 새 계획 세우기는 새 입력을 위해 비웁니다. 화면에 입력한 내용은 `textContent`로 반영하며 HTML로 해석하지 않습니다.

## 함께 사용할 수 있는 기능

- 과제 적기·마감 확인·완료 표시 탭과 과제 이름의 실시간 미리보기
- 완료 체크·해제, 다시 진행하기, 예시 넣기
- 상단 메뉴를 통한 페이지 내부 이동
- 빈 입력·형식 오류·확인 완료를 구분하는 이메일 형식 확인

미리보기 탭의 과목과 마감일은 예시입니다. 이메일은 형식만 확인하며 저장하거나 전송하지 않습니다.

## 화면과 키보드 조작

768px 이하에서는 메뉴·탭·입력 영역과 버튼을 세로로 배치합니다. 긴 과제 이름은 요약에서 줄바꿈합니다. 오류는 입력창 가까이에 표시하고, 단계가 바뀌면 다음 입력창이나 제목으로 초점을 옮깁니다.

Tab으로 조작 요소를 이동하고 Enter로 입력을 진행할 수 있습니다. 탭은 넓은 화면에서 좌우, 좁은 화면에서 위아래 방향키로 전환합니다. 확인 창에서는 Tab으로 두 버튼을 이동하며 Escape로 취소할 수 있습니다.

- 완료와 재시작: 완료 화면에 계획 표시, 새 계획의 값·오류·요약·진행 초기화, 마감일 없는 두 번째 계획 완료

각 단계에서 가로 넘침과 JavaScript·콘솔 오류가 없었고, 60자 이름도 요약 안에서 줄바꿈됐습니다. 실제 배포 스크린샷에서도 입력·오류·선택·확인·완료 화면의 잘림과 겹침이 없었습니다. 배포된 HTML·CSS·JavaScript가 저장소 코드와 일치하는 것도 확인했습니다.

## 실행 방법

저장소를 내려받아 `index.html`을 브라우저에서 열면 됩니다. HTML, CSS, JavaScript와 SVG로 구성되어 별도 빌드 과정은 없습니다. 화면 스타일은 `style.css`, 동작은 `script.js`에서 수정할 수 있습니다.
